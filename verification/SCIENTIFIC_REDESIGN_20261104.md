# TIMEVAULT scientific digital interface

## Scope

Presentation-only redesign responding to the supplied digital design and TIMEVAULT portfolio boards, followed by the user's request for innovative abstract backgrounds. Cover, reserve home, mode choice, STORE/RECLAIM selection, receipts, processing/outcomes, countdown, History and Reflection chrome share a dark marine instrument system while using different arrangements and optical treatments.

Cover: silver-blue TIME and violet chrome VAULT, original interactive light response, a reserved right apparatus stage, measured clock and compact controls. Digital time, reserve and captions occupy independent bands. No outer caption box. STORE has converging violet precision traces; RECLAIM has outward horizontal ice-blue refractions. History has independent etched archival strata. Background luminance stays below the installation and primary text.

Source edits: one new final CSS import in `client/src/main.tsx`, new `scientific-interface.css`, four new generated JPEGs and regenerated GitHub Pages `docs/`. Existing component, hook, hand math, worker, gesture particle, scene, shared and server source match baseline `e5e50ff` byte for byte. No dependency, content, account policy, timing, hand role, camera lifecycle or interaction change.
